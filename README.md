## 常见问题

### 访问入口打不开怎么办

先复制完整链接到浏览器打开。如果仍然无法访问，可以切换 Wi-Fi 或移动网络后再试，并回到本页查看入口是否有更新。

### 从聊天窗口点击后打不开怎么办

复制完整地址，使用浏览器打开；也可以在聊天 App 中选择“在浏览器中打开”。

### iPhone 可以使用吗

可以通过上方访问入口使用网页版。本页目前仅列出安卓 App 的下载入口。

### 下载或安装失败怎么办

请通过本页列出的下载入口重新尝试，确认设备有足够的存储空间。
